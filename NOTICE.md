ThemeBook is original MIT-licensed work.

Catalog discovery (user overlays win, preview file names, color keys) follows the same installed-theme layout as Omarchy’s `omarchy-theme-list` / `omarchy-theme-switcher` and the community theme-picker plugin at https://github.com/archlatam/omarchy-theme-picker (MIT). Panel-as-app summon follows the Omarchy shell plugin contract.

The stacked and grid picker layouts adapt navigation and preview-card patterns from Extended Theme Picker (https://github.com/ejuro/omarchy-extended-theme-picker, MIT), itself based on Omarchy’s image picker. Copyright David Heinemeier Hansson and Erik Johansson. ThemeBook does not vendor that plugin, its collection store, or `theme-collections.json`.
